      What these words mean
      Auction
      Orders are not matched one by one. Each round collects the standing orders and clears them all at one price.
      Microblock
      One numbered entry in a market's log, holding one auction's result. Its number orders events; it carries no certified time.
      Certified
      Signed by enough of the market's validators (the quorum). Only certified results move funds.
      Seats / quorum
      How many validators the market has, and how many must sign a result.
      Account sequence (Seq.)
      A counter in each request this wallet signs, so no request can be replayed or reordered.
      Verified by
      Who checked the market data before you signed: your own node's engine, or a remote trading endpoint you trust to report it.
      Payout
      A certified withdrawal, paid to its address by a B3 transaction this wallet publishes.

      Create a wallet

      Letters, digits, spaces, dots, dashes and underscores. The wallet loads every time the node starts until you close it.

      Back up

      Saves a copy of the wallet in use to a new file you choose. The copy holds the wallet's keys: keep it away from cloud-synced and shared folders.

      This backup is not encrypted
      The wallet has no passphrase, so anyone who can read the backup can spend its coins. Encrypt the wallet first, or keep the file on encrypted storage.

      Restore or recover

      Same rules as above. The wallet becomes the one in use.

      Restore from backup takes a wallet file saved by Back up, or by the B3 Qt wallet's Backup Wallet. Recover a legacy wallet takes the text file the old B3 wallet's dumpwallet command wrote. The node checks the whole file before it changes anything, then rescans the whole chain, which can take a long time.

      A dump file holds every key in plain text
      Once the recovered wallet shows its coins, encrypt it, back it up, and delete the dump file.
