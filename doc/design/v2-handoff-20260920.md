## What is present and what is not

Present: V1 curve-auction execution, per-market asset/B3 custody, independent
authenticated plaintext TCP, engine-off HTTPS/Qt trading, durable action and
signer history, fresh-market preliminary-agreement prototype, bounded delivery
recovery, action wake-up, exact seat-cache reuse and integrated regressions.
Metadata parser extraction is present; automatic issuer-authenticated metadata
distribution is not thereby implemented.

Absent: native arbitrary quote markets, shared cross-market balances,
cross-market atomic reservations, futures execution/margin/oracles/liquidation,
V2 certificates and activation/migration, and an approved complete PoS V2
protocol. The reserved futures transfer action numbers do not implement them.

Retained qualification: see the baseline report. Those tests were **not
rerun** during this documentation task. Its approximately 419 ms same-machine
median is not 200 ms, WAN qualification, or a V2 benchmark. The original
accessibility crash remains OPEN / UNRESOLVED.

## Important corrections to stale prose

1. Actual V1 has BLS finality; older “no finality gadget” text is superseded.
2. Actual producers use the epoch snapshot. Immediate STAKE spendability
   does not imply immediate removal from that snapshot.
3. Source pins the reorg horizon at 1,440; an older paragraph saying it is
   unchosen is stale.
4. Exact eligibility integer truncation is consensus, not interchangeable
   with approximate proportional-weight prose.
5. Mainnet local signing waits at least 20 blocks; the consensus minimum
   checkpoint depth is 12. They are different checks.
6. Explicit operator-trusted finality recovery exists in later V1 source.
   It does not revoke signatures and is not a V2 recovery proof.
7. Actual V1 trading fees are seller-paid 100 ppm native B3. The owner's
   two-sided 50 ppm quote-asset requirement is a **V2 change**, not a label fix.
